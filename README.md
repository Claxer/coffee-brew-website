# Coffee Brew Website

## Description

Coffee Brew Website is a modern and responsive coffee shop landing page built using HTML5 and CSS3. It is designed to showcase a coffee shop's products, services, and atmosphere through a clean and visually appealing interface.

The website includes multiple sections such as a hero banner, about section, featured coffee menu, customer reviews, image gallery, contact form, and footer. It also features responsive layouts, hover effects, and smooth scrolling for a better user experience.

This project was created to practice front-end web development skills, including semantic HTML, CSS Flexbox, CSS Grid, responsive web design, and creating professional website layouts.

---

## Features

- Responsive navigation bar
- Hero section with call-to-action buttons
- About Us section
- Featured coffee menu
- Why Choose Us section
- Customer reviews
- Coffee gallery
- Contact form
- Professional footer
- Back-to-top button
- Smooth scrolling navigation
- Responsive design for desktop, tablet, and mobile devices

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your preferred web browser.

You can also use the **Live Server** extension in Visual Studio Code for a better development experience.
